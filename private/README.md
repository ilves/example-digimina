# private/

Everything in this folder except this README is ignored by git (see `.gitignore`), so it never reaches GitHub or an app that syncs your repo from GitHub.

It is **not** a vault. AGENTS.md tells assistants not to read it, but a tool with file access on your computer (Claude Code, Codex and similar) technically can. Real secrets such as passwords and recovery codes belong in a password manager, not here.
