# Inbox

Drop anything here that should end up in your context but that you don't want to sort yourself: pasted notes, exported statements, voice-memo transcripts, screenshots described in text.

Then say **"Sort my inbox."** The AI proposes where each piece belongs, saves on your yes, and deletes the inbox item afterwards.

**Remove account numbers, ID codes and addresses before you drop a file here.** Once a file is committed, git remembers it even after it's deleted.
