# Areas

Each area is a folder with the same four files: `goals.md`, `rules.md`, `status.md`, `journal.md`. The AI keeps this table current.

**Set up next:** —

**Status:** `empty` (folder exists, not filled) · `planned` (chosen, folder not created yet) · `active` (in use) · `paused` (kept, but not read by default)

## Add an area

Say **"Add an area for <name>"**. The `area-interview` skill copies `_template/`, interviews you, and adds a row here.

Ready-made question banks exist for: investing, personal finance, health, career, home and family, learning. Any other area works too; the AI uses the generic question bank.

Ideas: side project, travel, relationships, creative work, volunteering, a renovation, a big purchase you're planning.
