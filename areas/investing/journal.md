# Investing — Decision journal

Append-only. Newest at the top. Write the entry **before or right after** a trade, not weeks later. Feelings count: they're what the AI looks for patterns in.

```
### YYYY-MM-DD — BUY/SELL/HOLD <what>, <how much: % of portfolio or units>
Why:
Rule check: <follows / breaks which rule>
Market mood: <calm / rising fast / falling fast>
How I felt: <calm / excited / FOMO / scared / panic / bored>
Review on: YYYY-MM-DD
```
