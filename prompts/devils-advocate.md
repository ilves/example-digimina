# Devil's advocate

Use it on any plan, purchase or investment thesis. Say: **"Devil's advocate on <thing>."**

```
Read the relevant files (the area's goals.md and rules.md, and the thesis
or plan if there is one). Then argue against it like a sharp, fair skeptic:
1. The three weakest assumptions, in order of how much they matter.
2. What I'm probably not seeing because of the blind spots in me.md.
3. Which of my own rules this bends or breaks.
4. What would have to be true for this to be a bad idea in a year.
Don't soften it, and don't tell me what to do. End with one question
I should answer before I go ahead.
```
