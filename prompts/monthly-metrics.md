# Monthly metrics

Say: **"Monthly metrics"**, or run it on the 1st of every month as a scheduled task (see `AUTOMATE.md`). It keeps a dashboard of progress up to date, so you can see the trend instead of a single snapshot.

```
Record last month's numbers for the goals in my active areas.
1. Read the "How I'll know / How I'll know I'm on track" sections of my
   areas' goals.md and the "Numbers worth tracking" tables in status.md.
2. For each number, read it from the tool in me.md (Where my data lives)
   when it's connected: portfolio tracker, training app, business
   dashboard. Use the last complete month, not the running one.
   Money: store progress in % (for example "% of my freedom number"),
   not balances, unless I've chosen otherwise.
3. Add one row for the month to my metrics table: a database in my
   notes or task tool if me.md names one, otherwise a "## Metrics" table
   in the area's status.md (shown to me first, saved on my yes).
   If a row for that month exists, update it instead of adding another.
4. Finish with five lines: what went up, what went down, compared with
   the month before.
```

Tip: charts are easiest in the tool that holds the table (for example a chart view on a Notion database). Fill in a few past months once so the chart starts with a trend.
