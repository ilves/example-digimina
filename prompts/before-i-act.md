# Before I act

For any decision with money, time or a relationship on the line. Say: **"Before I act: <what I'm about to do>."**

```
Before I do this, check it against my files:
1. Which goal in this area does it serve? Which does it work against?
2. Which of my rules does it follow, and which does it break?
3. Is there a pattern in my journal or decisions.md that looks like this?
   How did it go last time?
4. On a scale of 1–5, how reversible is it?
Then help me write a decisions.md entry with a review date (log-decision skill).
```
